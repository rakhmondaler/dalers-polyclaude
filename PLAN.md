### 2. `skills/council/references/synthesis.md` (высокий приоритет)

Трёхслойная система синтеза (заменяет бинарные Challenge Targets оригинального polyclaude):

- **Слой 1 — Совпадения (Convergence):** в чём перспективы согласны, несмотря на разные методы? Сильный сигнал.
- **Слой 2 — Дополнения (Complement):** как перспективы усиливают друг друга, добавляя разные измерения одного ответа?
- **Слой 3 — Коррекции (Correction):** где одна перспектива уравновешивает слепое пятно другой? Не конфликт, а поправка.

7-шаговая методология синтеза (адаптация из polyclaude):
1. Собрать все выводы и рекомендации.
2. Найти конвергенцию (одинаковые выводы из разных методов).
3. Картировать дополнения (разные стороны одной истины).
4. Обнаружить коррекции (где одна перспектива вытаскивает другую из слепой зоны).
5. Определить остаточные противоречия (если они есть) и квалифицировать их: ситуативные или фундаментальные?
6. Собрать финальную рекомендацию с указанием уровня уверенности.
7. Явно обозначить оставшиеся слепые зоны совета в целом.

## Дизайн-решения (для памяти)

- **Обезличенность:** никаких имён реальных людей — только архетипы. Убрано из всех файлов.
- **Три слоя связей** (Дополняет / Корректирует / Собственная слепая зона) заменяют бинарные Challenge Targets оригинального polyclaude. Причина: 11 мыслителей из традиций мудрости больше соглашаются, чем спорят; бинарная оппозиция искажает реальность.
- **Адаптивный выбор 3–6 перспектив** вместо фиксированных 6. Причина: разные типы вопросов требуют разных голосов.
- **Один универсальный совет**, не модульный. Причина: пользователь хочет универсальность, а не тюнинг под каждый сценарий.
- **Регламент коммитов:** каждая логическая единица = отдельный коммит + push. Позволяет пользователю видеть прогресс на GitHub и комментировать/править по ходу.
