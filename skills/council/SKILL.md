# Council — Совет из 11 когнитивных перспектив

Совет спавнит параллельные когнитивные перспективы для анализа вопросов, планов, идей и ситуаций с разных сторон, затем синтезирует результаты через трёхслойную систему (конвергенция / дополнения / коррекции).

## Когда использовать

Команда `/council` полезна, когда:
- Принимаешь значимое решение в жизни или карьере и хочешь проверить его с разных сторон
- Анализируешь клиентский проект, план или идею
- Разбираешься в сложных отношениях или конфликте
- Разрабатываешь или оцениваешь контент
- Нужен «красный тест» идеи
- Хочешь увидеть слепые зоны

## Когда НЕ использовать

- **Фактические и технические вопросы** — один точный ответ бьёт пять мнений. Юридическое, медицинское, тактическое решается экспертом, не философами.
- **Срочные решения** — совет занимает минуты и стоит денег; если решать надо сейчас, решай сейчас.
- **Решение дешевле анализа** — не запускай совет на вопрос, цена ошибки в котором ниже стоимости прогона.
- **Повторный заход на тот же вопрос без новых фактов** — совет даст тот же ответ другими словами. Сначала сделай что-то с прошлым вердиктом.
- **Запрос валидации уже принятого решения** — совет может её дать и зафиксировать тебя в неверном выборе.
- **Чтобы не решать** — если совет используется как ритуал откладывания, он кормит проблему, а не решает её.

## Совет

11 когнитивных перспектив, каждая — отдельный архетип с уникальной оптикой:

| Перспектива | Ключевая оптика |
|---|---|
| **Ангел-инвестор** | leverage, via negativa, компрессия в твит |
| **Воин** | ЧСВ, энергоаудит, тест смертью, путь сердца |
| **Эмпирический исследователь** | хрупкость/антихрупкость, skin in the game, Lindy |
| **Кодекс** | ближний, последний, бревно, граница vs. стена |
| **Психопомп** | тень, проекции, симптом как символ, Эго/Самость |
| **Бунтарь** | steelman, scout vs. soldier, пропущенный шаг |
| **Джняна-йоги** | нети-нети, вайрагья, карма/дхарма, тишина |
| **Космо-шут** | игра vs. война, обратный закон, у-вэй, смех |
| **Стратег-социопат** | уровни игры, темп, meta-уровень |
| **Техно-оптимист** | exit vs. voice, гейткиперы, отгрузка |
| **Биполярный артист** | вкус, одна нота, категорийный отказ |

## Как использовать

### Базовый
```
/council Стоит ли мне уходить с работы ради своего проекта?
```

### Размер совета
```
/council --quick Какой оффер выбрать?                 # 3 перспективы — быстро
/council Как выстроить стратегию запуска?              # 5 перспектив — стандарт
/council --full Как мне жить дальше?                   # 11 перспектив — полный совет
/council --council 7 Стоит ли менять нишу?             # точное число (3–11)
```

### Качество
```
/council --deep Куда двигаться в карьере?              # Opus — максимальная глубина
/council --full --deep Стоит ли менять нишу?           # Все 11 на Opus
```

### Управление составом
```
/council --include артист,космошут Какой контент-план?
/council --exclude стратег Как разрешить конфликт?
/council -y Стоит ли уходить?                         # пропустить подтверждение состава
```

Перед запуском агентов совет предлагает состав и ждёт подтверждения. Флаг `-y` / `--yes` пропускает этот шаг.

## Четыре домена

1. **Жизнь/Карьера** — личные решения, направление, состояние
2. **Клиентские проекты** — бизнес-идеи, стратегия, продукт
3. **Отношения** — конфликты, динамика, границы
4. **Контент** — посты, статьи, нарративы, бренд

Совет автоматически подбирает перспективы под домен.
