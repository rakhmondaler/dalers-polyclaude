# Council

**Совет из 11 когнитивных перспектив для Claude Code.**

Council запускает параллельные когнитивные перспективы для анализа вопросов, планов, идей и ситуаций с разных углов — затем синтезирует результаты через трёхслойную систему: конвергенция, дополнения, коррекции.

На выходе — не список мнений, а отчёт: в чём совет сошёлся, где одна перспектива поправляет слепую зону другой, что никто не увидел, и конкретная рекомендация.

---

## Установка

```bash
# Клонировать репо
git clone git@github.com:rakhmondaler/polyclaude.git

# Переключиться на ветку council
cd polyclaude && git checkout council
```

Перезапустите Claude Code. Команда `/council` будет доступна в сессиях.

## Использование

### Базовый

```
/council Стоит ли мне уходить с работы ради своего проекта?
```

### Размер совета

| Флаг | Перспективы | Для чего |
|------|------------|----------|
| `--quick` | 3 | Быстрая проверка |
| *(по умолчанию)* | 5 | Сбалансированный анализ |
| `--full` | 11 | Полный совет |
| `--council N` | 3–11 | Точное число |

```
/council --quick Какой оффер выбрать?
/council --full Как мне жить дальше?
```

### Качество

| Флаг | Что делает |
|------|-----------|
| *(по умолчанию)* | Sonnet — быстро |
| `--deep` | Opus — максимальная глубина |

```
/council --deep Куда двигаться в карьере?
/council --full --deep Стоит ли менять нишу?
```

### Управление составом

```
/council --include артист,космошут Какой контент-план?
/council --exclude стратег Как разрешить конфликт?
```

Имена: `ангел`, `воин`, `эмпирик`, `кодекс`, `психопомп`, `бунтарь`, `джняна`, `космошут`, `стратег`, `техно`, `артист`

## Совет: 11 перспектив

| # | Архетип | Ключевая оптика |
|---|---------|-----------------|
| 1 | **Ангел-инвестор** | leverage, via negativa, компрессия в твит |
| 2 | **Воин** | ЧСВ, энергоаудит, тест смертью, путь сердца |
| 3 | **Эмпирический исследователь** | хрупкость/антихрупкость, skin in the game, Lindy |
| 4 | **Кодекс** | ближний, последний, бревно, граница vs. стена |
| 5 | **Психопомп** | тень, проекции, симптом как символ, Эго/Самость |
| 6 | **Бунтарь** | steelman, scout vs. soldier, пропущенный шаг |
| 7 | **Джняна-йоги** | нети-нети, вайрагья, карма/дхарма, тишина |
| 8 | **Космо-шут** | игра vs. война, обратный закон, у-вэй, смех |
| 9 | **Стратег-социопат** | уровни игры, темп, meta-уровень |
| 10 | **Техно-оптимист** | exit vs. voice, гейткиперы, отгрузка |
| 11 | **Биполярный артист** | вкус, одна нота, категорийный отказ |

## Четыре домена

Совет автоматически подбирает состав под тип вопроса:

| Домен | Якорь | Контекст |
|-------|-------|----------|
| **Жизнь/Карьера** | Воин | Личные решения, направление, состояние |
| **Клиентские проекты** | Ангел-инвестор | Стратегия, продукт, бизнес-идеи |
| **Отношения** | Кодекс | Конфликты, динамика, границы |
| **Контент** | Биполярный артист | Посты, статьи, нарративы, бренд |

---

## Что отличает Council

- **Адаптивный совет** — состав подбирается под домен вопроса, а не фиксированный
- **Трёхслойный синтез** — конвергенция / дополнения / коррекции вместо бинарных оппозиций
- **Обнаружение слепых зон** — что ни одна перспектива не затронула
- **Карта уверенности** — где анализ крепкий, а где шаткий
- **Отчёт для действия** — конкретная рекомендация и следующие шаги
